# ✦ Frohe Weihnachten 2026 ✦

### GEDOPLAN wünscht frohe Weihnachten und einen guten Rutsch ins neue Jahr!


---


| | Spiel | Worum geht's? |
|---|---|---|
| 🕯️ | <a href="https://gedoplan.github.io/Frohe-Weihnachten-2026/" target="_blank"><b>Adventskranz</b></a> | Die Startseite: An jedem Adventssonntag geht eine weitere Kerze an – und mit ihr ein neues Spiel. Einfach auf eine brennende Kerze klicken. |
| 🃏 | <a href="https://gedoplan.github.io/Frohe-Weihnachten-2026/memory" target="_blank"><b>Memory</b></a> | Finde alle Paare – von der Zuckerstange über die Glühweintasse bis zur Angular-Kugel. |
| 💡 | <a href="https://gedoplan.github.io/Frohe-Weihnachten-2026/lights" target="_blank"><b>Lichterkette</b></a> | Betätige die Schalter, bis die ganze Weihnachtsbeleuchtung strahlt. Wie viele Züge brauchst du? |
| 🧩 | <a href="https://gedoplan.github.io/Frohe-Weihnachten-2026/sliding" target="_blank"><b>Schiebepuzzle</b></a> | Schiebe die Kacheln zurück an ihren Platz, bis das Weihnachtsbild komplett ist. |

## Unter der Haube

- <a href="https://angular.dev" target="_blank">Angular</a> 22 mit Standalone Components und Lazy Loading
- <a href="https://ngrx.io/guide/signals" target="_blank">NgRx Signal Store</a>

## Selbst ausprobieren

```bash
npm install
npm start
```

Danach <a href="http://localhost:4200" target="_blank">http://localhost:4200</a> öffnen und loslegen.
